# art-source

The artist's working files go here: layered PSD/Aseprite/Krita files, big exports, references.

Everything in this folder (except notes like this README) is stored with **Git LFS** (see `.gitattributes`), so large files don't bloat the repo. Nothing in here is published to the website.

When a piece is finished, **export** a game-ready PNG into the game's `assets/` folder. Those exports stay in regular Git so the website can show them.

Suggested folders:

- `characters/` – Bill and anyone else
- `backgrounds/` – room layers
- `ui/` – windows, buttons, icons

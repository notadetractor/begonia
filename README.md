# begonia

A narrative management sim where you manage SnarkGuyBill, a streamer who cares only about money and himself.

## What's in this repo

| Folder | What it is |
|---|---|
| `prototype/` | The HTML/JS design prototype: a playable 60-second stream. See `prototype/README.md`. |
| `art-source/` | The artist's original files, exactly as delivered. Stored with Git LFS. Not published. |
| `game/` | *(coming)* The Godot project for the full game. |
| `website/` | *(coming)* The project website. |
